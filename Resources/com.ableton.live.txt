# Shortcut reference for Ableton Live 12 (macOS), from the Live manual chapter "Live Keyboard Shortcuts".
# Format: "## Section" starts a section, then one "Action | Keys" per line.
# Keys use the manual's spelling: Cmd, Option, Shift, Ctrl run together, e.g. CmdShiftT.
